# `config/keepass-gdrive.config.sh`

KeePassXC with the vault folder kept in Google Drive and synced to a local folder.

```
wget -qO- https://raw.githubusercontent.com/kaspary/sysutils/main/config/keepass-gdrive.config.sh | tr -d '\r' | bash
```

The first run opens the browser to authorize rclone on Google Drive. The script is idempotent: a
rerun skips what exists and only refreshes the units and settings.

## Why this approach

The vault is a normal local file (`~/Documents/Keepass/*.kdbx`), synced both ways every few minutes:
- it works offline;
- KeePassXC saves safely (on a GNOME Online Accounts/GVFS mount of Drive it does not, and that needs
  network all the time);
- a change made on two computers between two syncs keeps both copies instead of overwriting one.

## What it changes

| Item | Details |
|---|---|
| Packages | `keepassxc` (plus `unzip`, `curl`, `python3`) |
| `~/.local/bin/rclone` | official rclone binary, checked against rclone's `SHA256SUMS`; updated when a newer version exists. No `sudo`, newer than the Ubuntu package |
| `~/.config/rclone/rclone.conf` | remote `gdrive` (Google Drive, scope `drive`) with the OAuth token, mode 600. Created only if missing |
| `~/.config/rclone/keepass-filter.txt` | only `*.kdbx` / `*.keyx` are synced |
| `~/Documents/Keepass` | local vault folder, mode 700 |
| `~/.cache/rclone/bisync/` | bisync state (the baseline) |
| `~/.config/systemd/user/keepass-sync.service` | one `rclone bisync` run |
| `~/.config/systemd/user/keepass-sync.timer` | 1 min after login, then every 5 min; `Persistent=true` catches up after sleep |
| `~/.config/keepassxc/keepassxc.ini` | `[General] AutoSaveAfterEveryChange=true`, `AutoReloadOnChange=true` |

Details:
- **Filter:** Drive allows two files with the same name in a folder, which breaks `bisync`. The
  filter keeps anything that is not a vault/key file out (those files are not touched).
- **First sync:** `rclone bisync --resync --resync-mode newer` creates the baseline. When the same
  file already exists on both sides (second computer), the newest copy wins.
- **Regular sync:** `--resilient --recover --max-lock 2m` recovers from interrupted runs;
  `--conflict-resolve none --conflict-loser num` keeps both versions of a file changed on both sides
  (the loser gets a numbered name). Merge them in KeePassXC: *Database → Merge from database*, then
  delete the extra copy.
- **KeePassXC settings:** save after every change (goes to Drive on the next sync) and reload the open
  vault when the sync replaces the file. KeePassXC rewrites its ini on exit, so close it while the
  script runs.

## Variables

| Variable | Default |
|---|---|
| `RCLONE_REMOTE` | `gdrive` |
| `RCLONE_DRIVE_CLIENT_ID`, `RCLONE_DRIVE_CLIENT_SECRET` | rclone's shared client |
| `KEEPASS_REMOTE_DIR` | `KeePass` |
| `KEEPASS_LOCAL_DIR` | `~/Documents/Keepass` |
| `KEEPASS_SYNC_INTERVAL` | `5min` |

## Day to day

```
systemctl --user start keepass-sync                 # sync now
journalctl --user -u keepass-sync                   # logs
systemctl --user list-timers keepass-sync.timer     # next run
```

## Google client id

**rclone's shared Google client id is being retired during 2026.** When the sync starts failing with
auth errors, create your own OAuth client id
([rclone docs](https://rclone.org/drive/#making-your-own-client-id)) and either:
- `rclone config update gdrive client_id=<id> client_secret=<secret>` then `rclone config reconnect gdrive:`; or
- remove the remote (`rclone config delete gdrive`) and rerun the script with
  `RCLONE_DRIVE_CLIENT_ID` / `RCLONE_DRIVE_CLIENT_SECRET`.

## Reverting

```
systemctl --user disable --now keepass-sync.timer
rm ~/.config/systemd/user/keepass-sync.{service,timer}
systemctl --user daemon-reload
```
The local vault folder and the Drive folder are left as they are.

## Maintaining

- The unit is generated by `install_timer`; rerun the script after changing it (it overwrites the units).
- If the local folder or the remote path changes, a new baseline is needed: the bisync state is keyed
  by both paths, so the script runs `--resync` again automatically for the new pair.
